# threshold-ecdsa

This project is an implementation of the threshold ECDSA protocol described in [CGGMP20](https://eprint.iacr.org/2021/060.pdf).

This implementation is based on the original [tss-ecdsa](https://github.com/boltlabs-inc/tss-ecdsa) repository.
